# Site de Commerce

Une plateforme e-commerce développée en PHP.

## Description

Ce projet est un site de commerce en ligne permettant de :
- Afficher des produits
- Gérer un panier d'achat
- Passer des commandes
- Gérer les utilisateurs

## Technologies utilisées

- PHP
- MySQL
- HTML / CSS
- JavaScript
- WAMP (en local)

## Installation

```bash
git clone https://github.com/odgyous0102-del/e-commerce-site.git
```

1. Copie le projet dans `C:/wamp64/www/`
2. Importe la base de données dans **phpMyAdmin**
3. Configure le fichier de connexion
4. Lance WAMP et ouvre `http://localhost/e-commerce-site`
